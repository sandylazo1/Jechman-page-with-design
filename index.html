Privacidad y datos personales

JECHMAN Ingeniería y Construcción SpA presenta este sitio informativo. Para consultas sobre tus datos puedes escribir a ventas@jechman.cl o contactar al equipo en Colo Colo 14405, La Pintana, Santiago. Esta información se refiere al sitio de GitHub Pages; el sitio oficial y los servicios externos tienen sus propias políticas.

El formulario, el configurador y la asistente Sofía preparan una consulta en tu navegador. Este sitio no recibe automáticamente los datos que escribes. Si decides abrir WhatsApp o enviar un correo, compartirás voluntariamente el mensaje con JECHMAN y con el proveedor de ese canal para atender tu solicitud y preparar una cotización. Evita incluir datos sensibles que no sean necesarios.

El sitio puede guardar en tu navegador la aceptación del aviso de privacidad y, durante la sesión, las selecciones de tu proyecto. No utiliza analítica ni publicidad propias. GitHub Pages puede tratar datos técnicos de acceso; al abrir enlaces externos, sus operadores aplican sus propias prácticas de privacidad. Puedes borrar los datos locales desde la configuración de tu navegador.

Puedes solicitar información, acceso, rectificación, cancelación u oposición cuando corresponda conforme a la Ley N.º 19.628, escribiendo al correo indicado. Conservaremos los datos que recibamos por los canales de contacto solo durante el tiempo necesario para responder y cumplir obligaciones aplicables; el plazo concreto puede depender de la relación comercial y de exigencias legales. No publicamos tus datos desde este sitio.

La Ley N.º 21.719 modifica el régimen de protección de datos, pero sus disposiciones principales comienzan a regir el 1 de diciembre de 2026. Esta página se revisará antes de esa fecha.

Condiciones del catálogo y las cotizaciones

Este sitio permite explorar productos y servicios y preparar solicitudes de cotización. No tiene pago ni cierre de compra en línea. Enviar una consulta no reserva un producto, no confirma una instalación ni constituye aceptación de una oferta. JECHMAN confirmará por escrito características, compatibilidad, disponibilidad, precio total, impuestos, despacho, instalación, plazos, garantías y cualquier condición específica antes de contratar.

Las medidas y capacidades publicadas sirven para orientar la consulta; la factibilidad del proyecto requiere evaluación. Las fotografías de productos JECHMAN se identifican como tales; otras imágenes son referencias visuales y no acreditan un modelo, obra o resultado específico. Las especificaciones de fabricantes y las condiciones comerciales se confirman con el equipo.

La información de esta página puede actualizarse; las condiciones efectivamente ofrecidas o contratadas por escrito se respetarán. No se interpretará ninguna cláusula de esta página como renuncia a derechos irrenunciables de las personas consumidoras.

Derechos del consumidor

La garantía legal, el retracto cuando proceda y las vías de reclamo se evaluarán según el producto, el servicio y la forma de contratación.
