# JECHMAN · Refinamiento visual y funcional

Actúa como diseñador de producto, desarrollador frontend y revisor de seguridad. Mejora la web estática de JECHMAN sin cambiar su identidad editorial ni introducir precios. Conserva la cotización como acción principal.

## Criterios de entrega

1. Evita repetir una misma fotografía en tarjetas contiguas o dentro de una misma colección. Cada imagen debe describir con claridad el título que acompaña. Distingue fotografía real de visual conceptual.
2. Publica las medidas de piscinas como texto HTML seleccionable. Las fotos entregadas contienen una tabla incorporada: encuadra únicamente la porción fotográfica en la interfaz y evita mostrar dicha tabla.
3. En electricidad, coloca la demostración «Prueba cómo respondería tu espacio» inmediatamente después de «Explora el alcance de tu proyecto». Retira el bloque «La luz transforma el espacio» y las secciones estáticas redundantes. Mantén una sección «Áreas de trabajo» con fotografías pertinentes y enlaces útiles.
4. Usa movimiento sutil, tipografía expresiva y líneas vectoriales como recursos de identidad. Las interacciones deben responder en unos 180 ms, respetar el teclado y `prefers-reduced-motion`, mantener legibilidad y funcionar en móvil.
5. No copies componentes, diseños ni recursos con licencia restringida de referencias externas. Prefiere CSS y JavaScript locales, sin rastreadores ni dependencias de ejecución adicionales.
6. Revisa rutas, imágenes, cotizaciones a WhatsApp, errores de consola, ancho móvil y despliegue de GitHub Pages antes de publicar.
