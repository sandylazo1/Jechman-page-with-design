# Auditoría de la iteración JECHMAN · 17 de octubre de 2026

## Alcance revisado

Se revisaron los HTML activos y el original, `news.json`, README, documentación y recursos de `assets/`, junto con el historial de la rama. Se comprobaron la portada publicada, las vistas por hash, el catálogo y los formularios. El sitio oficial de JECHMAN se consultó para comprobar datos corporativos; Perfect Pool se tomó como referencia de organización de categorías y descubrimiento comercial, sin copiar contenido.

## Hallazgos verificados

| Prioridad | Hallazgo | Acción |
| --- | --- | --- |
| P0 | El menú móvil no gestionaba Escape, foco ni clic fuera. | Se incorporaron cierre y foco restaurado, estado `inert` y atributos ARIA. |
| P1 | Georgia, Segoe UI y Arial competían en la jerarquía. | Se aplicaron Manrope e Inter autoalojadas, con licencias OFL. |
| P1 | La portada repetía categorías en seis tarjetas uniformes. | Se creó un selector visual de tres divisiones y se acortó la selección de soluciones. |
| P1 | Varias imágenes bajo el primer viewport se solicitaban inmediatamente. | Se aplicó carga diferida a tarjetas, noticias y sección institucional. |
| P1 | El cambio de diapositiva principal era abrupto. | Se añadió transición breve entre imágenes y textos con alternativa de movimiento reducido. |
| P2 | La ficha del catálogo no sugería alternativas relevantes. | Se muestran hasta tres productos de la misma categoría. |
| P2 | La presentación del logotipo mostraba un recuadro claro. | Se ajustó su integración mediante CSS, conservando el archivo original. |

No se verificaron precios, stock, descuentos, testimonios ni perfiles sociales recientes. Por eso no se añadieron esas afirmaciones. El catálogo mantiene su función de cotización y el sitio oficial permanece intacto.
