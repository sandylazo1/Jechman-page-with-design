# Prompt de ejecución — JECHMAN, experiencia profesional

Actúa como dirección de diseño, ingeniería frontend y revisión de conversión para el repositorio existente `sandylazo1/Jechman-page-with-design`. Mejora la página publicada sin reconstruirla ni modificar `www.jechman.cl`. Conserva rutas, imágenes autorizadas, catálogo, formularios y cotización por WhatsApp. Publica en la rama que alimenta GitHub Pages y deja el PR abierto hacia `main`.

## Resultado de diseño

1. La portada debe explicar en pocos segundos que JECHMAN reúne piscinas y bienestar, electricidad e ingeniería, y suministros. Redacta beneficios concretos para quien necesita elegir, instalar y mantener. Evita promesas de stock, descuentos, plazos, certificaciones o servicios no verificados.
2. Usa composición editorial: titulares breves, fotografía existente, navegación clara, superficies sólidas, esquinas moderadas, contraste alto y movimiento contenido. Mantén celeste para bienestar, amarillo para electricidad y morado solo para comercializadora; navy como base común. Evita apariencia de juego, gradientes morados decorativos y botones redundantes.
3. Conserva el carrusel principal y la franja superior; haz que roten cada 2 segundos. Automatiza también «Novedades JECHMAN» cada 2 segundos cuando esté visible. Mantén controles manuales y una pausa accesible al teclado; detén movimiento por preferencia de movimiento reducido, foco de teclado o pestaña oculta.
4. Transforma a Sofía en una guía de tres niveles: primero las tres áreas oficiales, luego subsecciones pertinentes, y después nombre, teléfono y ciudad. Respuestas breves, WhatsApp prellenado, sin precios ni envío automático.
5. Conduce a la cotización con motivos reales: compatibilidad, orientación técnica y una solicitud preparada. Nada de escasez o urgencia inventada. Toda CTA debe tener destino útil.

## Revisión

Verifica portada y bot a 320, 390 y 1440 px, carruseles y movimiento reducido, foco de teclado, enlaces, WhatsApp, accesibilidad automática y ausencia de desbordes. Comprueba la URL pública tras el push.
