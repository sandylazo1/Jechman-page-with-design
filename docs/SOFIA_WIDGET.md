# Sofía: asistente guiada de cotización

El código adjunto por el usuario se integró como archivos locales `assets/sofia-chat.js` y `assets/sofia-chat.css`, montados en `index.html` y `glassindex.html`. Así se preservan los estilos y scripts existentes y la página funciona en GitHub Pages sin servidor.

Sofía pregunta requerimiento, nombre, teléfono/WhatsApp y comuna o ciudad en pasos breves. Da una orientación general según el tema. Después prepara un enlace a WhatsApp que la persona debe abrir, revisar y enviar. No registra solicitudes, no almacena la conversación, no ofrece atención humana en vivo y no usa un servicio de IA externo. Los datos permanecen en la pestaña hasta que se cierre o recargue.

El botón usa profundidad y órbitas CSS inspiradas en experiencias 3D, sin incrustar escenas ajenas ni agregar dependencias. Se detiene con movimiento reducido; el panel admite teclado, cierre con Escape y disposición móvil. La integración se publica desde la rama `feature/jechman-glassmorphism-news`, configurada como fuente de GitHub Pages.
